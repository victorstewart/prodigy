# Support

For setup questions, reproducible failures, and feature discussion, use [GitHub Issues](https://github.com/victorstewart/prodigy/issues). Include the Prodigy revision, host architecture and kernel, command, relevant redacted output, and whether the run used the Apple Container or Linux disposable boundary.

Do not include credentials, tokens, private keys, deployment secrets, or unredacted provider configuration. Use [SECURITY.md](SECURITY.md) for a potential vulnerability.

Start from the task map in [documentation](prodigy/docs/README.md); first-service and evaluation-bundle commands remain candidate documentation until clean-room verification is recorded.
